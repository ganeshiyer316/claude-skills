# Claude skills

Open-source skills for Claude, by [Ganesh Iyer](https://github.com/ganeshiyer316). Each one comes from something I use in my own work and side projects.

## Skills

| Skill | What it does | Added |
|---|---|---|
| [be-ambitious](skills/be-ambitious) | Pushes any goal or task further along altitude, depth, range and show, and returns a stretch target, an outside judge and next moves. | 10/2026 |

## Install

- **Claude Code:** copy a skill's folder (e.g. `skills/be-ambitious`) to `~/.claude/skills/`, or clone this repo and run `./sync.sh` to link them all.
- **Claude app:** download the skill's `.zip` from [Releases](../../releases) and upload it as a custom skill.

## Feedback

Open an issue if a skill misfires or you've improved one. Pull requests welcome.
