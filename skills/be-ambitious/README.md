# be-ambitious

A Claude skill that pushes any goal, project or task further, and hands back a stretch target, an outside judge, three moves for this week and a sharper prompt.

It's built on the kinds of ambition in Anthropic's post "How to be more ambitious: A tutorial for humans with models" (October 2026): **altitude** (the goal behind the goal), **depth** (how the best in the field would do it) and **range** (borrowing from fields the task doesn't obviously need). I've added:

- **Goal types**, so a learning project isn't judged like a revenue one
- **A Show lens**, which asks what the work could produce that's worth sharing
- **Portfolio mode**, for when you're running several goals and need moves that serve more than one

## Install

- **Claude Code:** copy this `be-ambitious` folder to `~/.claude/skills/`.
- **Claude app:** download `be-ambitious.zip` from the latest release and upload it as a custom skill.

## Use

Ask Claude to "be ambitious about" a goal, or run `/be-ambitious`, then describe the goal, the time you really have, and what you've planned so far. List several goals at once for portfolio mode.

## Principles

- No invented numbers, customers or precedents
- Borrow experts' methods, not their voices
- The model never grades its own work: every plan names an outside judge
- Ambitious means deeper, not just bigger
